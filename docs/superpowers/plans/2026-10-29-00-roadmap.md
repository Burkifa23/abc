# ABC Learning Platform: Roadmap

This index lists every plan and the order to run them in.
Spec: `docs/superpowers/specs/2026-10-29-abc-learning-platform-design.md`.

| Order | Plan | Depends on | Produces |
|---|---|---|---|
| 1 | [01 Learning platform](2026-10-29-01-learning-platform.md) | — | MDX lessons, `<Quiz>`, `<CodeExercise>` (Monaco + solc), diagrams, progress, coverage check |
| 2 | [02 Lab infrastructure](2026-10-29-02-lab-infrastructure.md) | — | `lab.json`, `scripts/sync-labs.mjs`, `scripts/verify-lab.sh`, labs CI, the lab recipe |
| 3 | [03 Course content](2026-10-29-03-course-content.md) | 01 | 83 lessons in 10 modules covering all 229 docs sections |
| 4+ | [Lab plans](labs/) (01–20) | 02 | One Codespaces lab per plan |

Plans 01 and 02 don't depend on each other and can run in parallel. Both edit `site/src/pages/index.astro`,
so merge 01 first and rebase 02. Module tasks in plan 03 can run in
parallel once plan 01 is merged. Lab plans can run in parallel once plan 02 is merged. The suggested order
for labs is their number, because each lab's README links back to concepts from the earlier labs.
